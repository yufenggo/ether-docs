# ADR-0001：采用架构决策记录（ADR）

- **状态**：accepted
- **日期**：2026-06-19

## 背景
需要一种轻量、可追溯的方式记录重大技术决策的"为什么"，供人和 AI agent 查阅。

## 决策
采用 ADR：每个决策一份编号文件（`NNNN-标题.md`），不可变；被取代时新建一条并把旧条状态改为 `superseded`。

## 影响
- 文档说"是什么"，ADR 说"为什么"。
- 引入新运行时依赖、改变对外契约等，应先有 ADR。
